# cycle-map

Simple cycle route planner

http://cycle-map.liam.geek.nz/

* use pins to plan route and measure distance
* route is saved in URL for easy bookmarking and sharing
* works offline as long as map tiles are cached
* using [Leaflet](https://leafletjs.com/) map library
* using [Thunderforest](https://www.thunderforest.com) [OpenCycleMap](https://www.opencyclemap.org/) tiles
* generated from [OpenStreetMap](https://www.openstreetmap.org) data
